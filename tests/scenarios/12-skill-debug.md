# Scenario 12: skill-debug

`builtin-skills/debug/SKILL.md` teaches the structured 5-step debugging process.

## Required Content

- `/debug` invocation syntax
- Step 1: Reproduce
- Step 3: Hypothesise (≥3 hypotheses)
- Step 4: Verify
- Step 5: Fix
- Regression test requirement
- JSON output format

## The 5-Step Process

```
Reproduce → Isolate → Hypothesise → Verify → Fix
```

This matches the debugging pattern Claude Code recommends and ensures reproducible, documented bug fixes with regression tests.
