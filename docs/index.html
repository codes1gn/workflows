Features

Parallel agent coordination, finally simple

workflows brings Claude Code's best orchestration patterns to Copilot and Cursor as installable skills.

🚀

Parallel Execution

Spawn N subagents simultaneously, each working on a different aspect of the same task. Results merge automatically into a single output.

🔄

Sequential Pipelines

Chain agents where each one receives the previous agent's output. Build multi-stage review, transform, and validate pipelines.

🎭

Role-Based Agents

Pre-built roles: security-reviewer, perf-analyst, test-writer, doc-generator. Each has a tuned system prompt baked into the workflow.

📋

Result Aggregation

Smart merge strategies: dedup findings, rank by severity, synthesize conflicting agent opinions into a consensus recommendation.

📁

File-Scope Routing

Automatically shard work by file type, directory, or module boundary. Each agent receives only the files relevant to its role.

🔌

Extensible

Define your own workflow in a simple YAML schema. Add custom agents, override prompts, wire custom merge functions. No framework lock-in.

Install the skill

Drop the skill into your Copilot or Cursor skills folder and you are ready.

$ git clone https://github.com/codes1gn/workflows
$ cp -r workflows/skills/* ~/.github/skills/
# In your AI chat: /workflow parallel-review src/
