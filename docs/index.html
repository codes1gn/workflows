Installation

Up and running in 3 steps

1

Install the CLI

Requires Python 3.9+

git clone https://github.com/codes1gn/workflows
cd workflows
pip install -e .
2

Install Skills

Copy skill files to your AI assistant's skills directory

# GitHub Copilot (VS Code)
cp -r builtin-skills/* ~/.copilot/skills/
cp SKILL.md ~/.copilot/skills/workflows/

# Cursor IDE
cp -r builtin-skills/* ~/.cursor/skills/
cp SKILL.md ~/.cursor/skills/workflows/
3

Set API Key (for real agents)

Without a key, the harness runs in fast simulation mode

export ANTHROPIC_API_KEY=sk-ant-...
# or
export OPENAI_API_KEY=sk-...

Workflow YAML Schema

Define any multi-agent workflow in a simple YAML file

name: my-workflow
description: What it does
version: 1.0.0
max_parallel_agents: 8   # hard cap: 16
max_total_agents: 100    # hard cap: 1000

phases:
  - name: research
    agents: 6
    parallel: true
    prompt_template: |
      Query: {{query}}
      Agent {{agent_index}}: research angle {{agent_index}}

  - name: report
    agents: 1
    depends_on: [research]
    prompt_template: |
      Synthesize: {{phases.research.results}}
